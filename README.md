# Printivo Landing Page

This project is a static storefront landing page inspired by Printivo, a Nigerian print-on-demand and promotional products brand. It was built as a front-end mockup using HTML and CSS, with responsive styling for desktop and mobile views.

## Features

- Responsive navigation and top bar
- Hero section with search prompt
- Product cards for popular print items
- Trust and partner brand sections
- Customer reviews and social proof
- Footer with company information and links

## Project Structure

- `index.html` – page structure and content
- `style.css` – desktop styling
- `phone.css` – mobile responsive styling
- `images/` – assets, logos, and product images

## Local Preview

Open `index.html` directly in a browser, or run a lightweight local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
